# Review current changes

1. 変更されたファイルと差分を確認する。
2. 変更箇所の周辺実装を確認する。
3. 関連するテストを確認する。
4. 問題が成立する入力または実行経路を確認する。
5. 問題がある場合は、ファイル、場所、成立条件、影響、根拠を報告する。

根拠を確認できない内容は問題として断定しない。必要な情報を読み取れない場合は、確認できなかった範囲を明記して判断を保留する。
